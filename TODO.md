# Gelecek Geliştirmeler

## OpenCode kurulumunun otomatik tespiti

Durum: Henüz uygulanmadı. Daha sonra talep edilirse eklenecek.

Otomatik tespit şu sırayla yapılmalı:

1. PATH içinde `opencode.exe` aranır.
2. `C:\Programs\Opencode\opencode.exe` kontrol edilir.
3. Bulunamazsa kullanıcıdan kurulum konumunu seçmesi istenir.

Yalnızca PATH içinde bulunamaması, OpenCode'un kurulu olmadığı anlamına gelmez.
Mevcut sihirbaz, OpenCode'un önceden kurulması gerektiğini Türkçe ve İngilizce
olarak bildirir; otomatik tespit yapmaz.
